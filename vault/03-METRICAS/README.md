# 03-METRICAS — Resultados por marca
Estructura obligatoria: `03-METRICAS/<slug>/AAAA-MM-<plataforma>.md`.

- Métricas clave: retención media, % vistas completas, CTR, alcance, seguidores.
- Enlaza el guion de origen (`[[01-GUIONES/<slug>/...]]`) de la misma marca.
- Comparar marcas solo con métricas agregadas y por pedido explícito.
- No guardar exportaciones con datos personales ni tokens de API.
