# 00-INBOX — Captura cruda
Ideas, notas de voz transcritas, links y borradores sin procesar.

- Cada nota debe llevar frontmatter `marca: <slug>` o `marca: sin-asignar`.
- Las notas `sin-asignar` no se usan para producir hasta clasificarlas.
- Procesar periódicamente: mover a `01-GUIONES/<slug>/` o a `99-CUARENTENA/`.
- Nombre sugerido: `AAAA-MM-DD-<slug>-<tema>.md`.
