# Fase 3 — Enrutador dinámico y primer render de KUTT

## Decisiones
- **Entrada única**: `engine/src/Root.tsx` llama a `registerRoot` y registra la
  composición `BrandRouter` (30 fps, 1080x1920, 150 frames). Props validadas con
  Zod: `marca` (los 5 slugs), `skillTarget` (los 5 skills) y `titulo` (opcional).
- **Diccionario de temas**: `engine/src/utils/themeProvider.ts` es espejo
  tipado de `vault/04-MARCAS/` (`satisfies Record<BrandSlug, BrandTheme>`).
  Es el único archivo con colores de marca. `getTheme(marca)` entrega solo
  el tema pedido: ningún skill ve el diccionario entero (aislamiento).
- **Campos NO DEFINIDO** del vault quedan como `null` en el tema. El motor usa
  valores técnicos neutros: `NEUTRAL_TEXT` #FFFFFF y la fuente del sistema.
  No son identidad de marca y se reemplazan cuando el vault se complete.
- **Skills** (`engine/src/components/skills/`): contrato común
  `SkillProps { theme, titulo }`. `OpusCard` está implementado (dashboard
  isométrico con KPIs y barras animadas). `Hyperframes`, `PaperShades`, `Lemo`
  y `CloudAnimationBase` son esqueletos funcionales.
- **Metal López**: el tema separa `acento` (Teal) de `cta` (Coral) para que el
  Coral solo se pueda usar en CTAs y advertencias.
- **Script de prueba**: el CLI de Remotion lee el 2.º argumento como ID de
  composición. Por eso el script incluye `BrandRouter`:
  `remotion render src/Root.tsx BrandRouter out/kutt-test.mp4 --props=…`.

## Verificación
- `npx tsc --noEmit` → 0 errores.
- `npm run render:test-kutt` (con `REMOTION_BROWSER_EXECUTABLE` = Chromium
  preinstalado) → `out/kutt-test.mp4`, 2 MB, exit 0.
- ffprobe: h264 · 1080x1920 · 30/1 fps · 150 frames · 5.0 s.
- Fotograma 90 revisado: dashboard isométrico en Glaciar Cyan #00C4B4 sobre
  Deep Slate #0A1218.

## Pendientes
- La tipografía Archivo (KUTT) no está instalada: el render usó la fuente del
  sistema. Igual pasa con Montserrat y Poppins; Inter sí está. Para cargarlas
  hay que añadir los archivos de fuente al repo o instalar `@remotion/google-fonts`,
  y lo segundo requiere el permiso de npm.
- Los logos son placeholders vacíos y los skills todavía no los usan.
- Siguen `NO DEFINIDO`: el color de texto de kutt, metal-lopez, vitaly y
  nicolas-lopez, y la tipografía y la ruta del logo de mente-estrategica.
