# Nombre del repositorio: se conserva `Mente.estrategica`

## Contexto
Se evaluó renombrar el remoto `ayerestardeya/Mente.estrategica` a
`mi-mundo-engine`, porque el repo es el motor universal y Segundo Cerebro de
todo el ecosistema y no de una sola marca.

## Decisión (revisada)
- **No se renombra.** `Mente.estrategica` es el nombre definitivo del monorepo
  universal (local y remoto). "Mi Mundo Engine" es solo el nombre del sistema.
- La marca `mente-estrategica` sigue siendo un tenant más, con el mismo
  aislamiento que el resto. Que el repo se llame igual no le da prioridad ni
  acceso a datos de otras marcas.

## Historial
- 2026-11-17: primero se aprobó renombrar a `mi-mundo-engine`; ese mismo día se
  revocó y se decidió conservar el nombre actual.
