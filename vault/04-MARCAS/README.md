# 04-MARCAS — Identidad de marca (fuente de verdad)
Un archivo por marca: `<slug>.md`. El agente **debe** leerlo antes de crear
componentes Remotion o renderizar. Campos `PENDIENTE` = bloqueo: pedir datos.

| Slug                | Archivo                |
|---------------------|------------------------|
| mente-estrategica   | `mente-estrategica.md` |
| metal-lopez         | `metal-lopez.md`       |
| kutt                | `kutt.md`              |
| vitaly              | `vitaly.md`            |
| nicolas-lopez       | `nicolas-lopez.md`     |

Añadir una marca nueva requiere: archivo aquí + fila en `CLAUDE.md` +
decisión en `02-DECISIONES/`.
