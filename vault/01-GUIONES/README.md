# 01-GUIONES — Guiones aprobados por marca
Estructura obligatoria: `01-GUIONES/<slug>/AAAA-MM-DD-<titulo>.md`
(slugs válidos: mente-estrategica, metal-lopez, kutt, vitaly, nicolas-lopez).

- Frontmatter mínimo: `marca`, `estado` (borrador|aprobado|renderizado),
  `formato` (short|reel|largo), `fps` (default 30).
- Un guion nunca referencia assets, copys ni guiones de otra marca.
- Antes de producir, el agente lee `04-MARCAS/<slug>.md`.
