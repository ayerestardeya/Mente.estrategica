# vault/ — Segundo Cerebro (Obsidian)
Abre esta carpeta como vault de Obsidian. Regla de oro: **una marca por
carpeta/archivo**; todo archivo de contenido lleva `marca: <slug>` en frontmatter.

| Carpeta          | Propósito                                      |
|------------------|------------------------------------------------|
| `00-INBOX`       | Captura cruda, sin clasificar                  |
| `01-GUIONES`     | Guiones aprobados, por marca                   |
| `02-DECISIONES`  | Decisiones fechadas (ADR ligeros)              |
| `03-METRICAS`    | Resultados de publicación, por marca           |
| `04-MARCAS`      | Identidad de cada marca (fuente de verdad)     |
| `99-CUARENTENA`  | Material dudoso o con marca mal etiquetada     |
