# 99-CUARENTENA — Material retenido
Aquí va todo lo que no puede usarse con seguridad:

- Archivos sin `marca:` o con marca que no coincide con su carpeta.
- Contenido con posible mezcla entre marcas.
- Material con datos sensibles detectados.

El agente nunca usa nada de esta carpeta para producir. Solo un humano lo
libera (moviéndolo a la carpeta correcta) o lo elimina.
